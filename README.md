# Course Description 
This workshop introduces beginners to Python programming and data analysis, with no prior coding experience required. We'll start with the essentials: setting up your coding environment in Google Colab, getting comfortable with GitHub basics, and learning to read and write core Python syntax. From there, we'll explore various data analysis methods and how AI coding assistants (from simple autocomplete tools to more advanced agents) can support your research.

By the end, you'll have a working foundation in Python, practical experience with real data, and a clearer sense of how AI tools fit into (and can accelerate) your own work!
